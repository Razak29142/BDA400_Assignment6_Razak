
# BDA400 Assignment 6 – Stock Portfolio Technical Analysis Dashboard

**Student:** Razak Mohammad  
**Course:** BDA400 – Data Science Tools

## Project Overview
This project develops an interactive stock analysis dashboard using R and Shiny. It allows users to explore historical stock prices, technical indicators, and trading signals.

## Features
- Stock symbol selection
- Custom date range
- Daily, weekly, and monthly analysis
- Line and candlestick charts
- Short-term and long-term moving averages
- Relative Strength Index (RSI)
- MACD and signal line
- Buy, Sell, and Hold trading signals
- Recent trading signals table

## Technologies
R, Shiny, ggplot2, quantmod, TTR, dplyr, and xts.

## How to Run
1. Open the project in Posit Cloud or RStudio.
2. Install the required R packages.
3. Open `app.R`.
4. Click **Run App**.

## Testing
The dashboard was tested using AAPL stock data with daily, weekly, and monthly timeframes. Charts, technical indicators, and trading signals were reviewed.
